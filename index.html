An internal tool the operator of mahyeong Studio uses to manage the YouTube channels they own.

기능 / Features

기능Feature
운영자 채널에 영상 업로드, 공개 예약Upload videos to the operator's channel and schedule publishing
썸네일 설정, 제목·설명·공개 상태 등 메타데이터 관리Set thumbnails and manage metadata such as title, description, and privacy status

사용 범위 / Who can use it

  • 이 앱은 운영자 본인 소유의 YouTube 채널에만 사용합니다. 일반 사용자에게 공개된 서비스가 아니며, 가입 기능이 없습니다.
  • This app is used only for YouTube channels owned by the operator. It is not a public service and has no sign-up.
  • 이 앱은 YouTube API Services를 사용합니다. 앱을 사용하면 YouTube 서비스 약관에 동의한 것으로 봅니다.
  • This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service.
